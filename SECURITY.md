# Security policy

This is an early-stage research implementation, not a hosted service.
Report vulnerabilities privately through GitHub's security advisory feature
if enabled, not through public issues containing exploitable details.

Videos, voices, transcripts, embeddings and thumbnails may contain sensitive
personal information. Do not use this software with sensitive footage unless
appropriate access control, encryption, deletion and retention controls exist.
The project will not claim these protections until they are implemented and tested.
Never commit sample media without documented permission.
